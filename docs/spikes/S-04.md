# S-04 basedpyright と ruff server の起動と主要要求

実施日 2026-10-29。Windows 11 Home 10.0.26300、CPython 3.12.11、`basedpyright` 1.40.2（pyright 1.1.414 相当。Node は `nodejs-wheel-binaries` 24.19.0 が同梱）、`ruff` 0.17.3。判定: **合格**（basedpyright で起動・`initialize`・診断・`definition`・`references`・`hover`・`rename`・`callHierarchy` が通り、ruff の診断・quickfix・organizeImports も通った）。ただし macOS / Linux は未実施（CI で確認）。設計書 §7.5 に直す点が 9 つある。

## 確かめたこと
`.venv` の `basedpyright-langserver --stdio` と `ruff server` を自作の最小 LSP クライアント（Content-Length 枠、`spikes/s04_lsp/lsp_probe.py`）で起動し、`positionEncodings: ["utf-8","utf-16"]` を提示して `initialize` → `didOpen` → 診断、ADR-15 の各要求、`didChange` 後の診断の版、`shutdown` → `exit` → 終了確認までを実測した。フィクスチャは `spikes/s04_lsp/fixture_py/`（型エラー・未使用 import・乱れた import）。応答時間は「同じ要求を 1 回（冷）＋ 10 回（温）」の温の中央値で、同一要求の繰り返しなのでサーバー内キャッシュが効いた下限に近い。追加実測は `probe_extra.py`、基本スイートは `run_s04.py`。

追加の観察（basedpyright）:
- **`initializationOptions` ではインタープリタを渡せない**。`{pythonPath}`・`{python:{pythonPath}}` のどちらも効かず、`.venv` を `PATH` から外した環境で `dulwich` が `reportMissingImports` のまま。**`workspace/configuration` の `python` セクションで `{"pythonPath": ...}` を返すと解決**（`out/interp.json`、`probe_extra.py pypath`）。サーバーが尋ねるセクションは `python` と `basedpyright` の 2 つ。
- **診断メッセージが OS ロケールで日本語になる**。`initialize` に `locale: "en"` を渡すと英語（`"ja"` や未指定は日本語）。
- **ディスクだけ書き換えても依存元の診断は更新されない**（3 秒待っても無し）。`workspace/didChangeWatchedFiles`（`type: 2`）を送ると 40 ms で再発行された。このとき依存元（`didChange` していない `app.py`）の診断の `version` は**自分の旧い版（1）のまま**。
- `diagnosticMode: openFilesOnly` では開いた文書の診断しか来ない（`references` / `rename` / `callHierarchy` は未オープンの文書も対象）。
- 複数文書を続けて開くと、最初の `publishDiagnostics` に**同じ版（1）の空の診断**が混じり、実診断は約 75 ms 後（`$/progress end` と同時）。3 回とも、先頭で開いた文書だけは最初から実診断。

## 設計への反映
1. **§7.5.1 表（Python types）**: 起動は `<.venv>/Scripts|bin/basedpyright-langserver[.exe] --stdio`（Node の別途導入は不要）で確定。「インタープリタは `initializationOptions` / `workspace/configuration`」を **「`workspace/configuration` の `python` セクションだけ」** に直す（`initializationOptions` は効かない）。`on_request("workspace/configuration")` は MUST。
2. **§7.5.1 `LspServerDef`**: `position_encoding_default` は basedpyright=`"utf-16"`、ruff=`"utf-8"`（応答の `positionEncoding` が無ければ既定を使う）。`locale: str | None` を足し、basedpyright は **`"en"`**。`workspace/configuration` の返答を作る `config_for(section)` を足す。`requests_m1` は basedpyright に `definition / references / hover / prepareRename / rename / callHierarchy`、ruff に `codeAction / codeAction/resolve`。
3. **§7.5.1 の役割分担**: Python の `codeAction`（quickfix・organizeImports・fixAll）は **ruff が供給元**。basedpyright の quickfix は `# pyright: ignore` だけで、`source.organizeImports` は返らない。`LspFeatures.code_actions` は Python では ruff に送り、basedpyright には送らない。`resolve_code_action` は ruff のためにある（`data` あり・`edit` 無しが返る）。
4. **§7.5.3 手順 4（URI）**: 受信 URI は正規化してから `confine` に渡す（`unquote` → 先頭の `/` を落とす → `os.path.normcase(realpath)`）。basedpyright は小文字ドライブ＋`%3A` で返す。
5. **§7.5.6 `rename` / `code_actions`**: `WorkspaceEdit` は `changes` と `documentChanges` の**両方の形**を `Plan` に変換する（basedpyright の rename は `documentChanges`、codeAction・organizeimports は `changes`、ruff は `documentChanges`）。`textDocument.version` は `null`（版検査なし）。`resourceOperations` はどちらも 0 件だったが、含まれたら `E_UNSUPPORTED`（設計どおり）。
6. **§7.5.5 版待ち**: 手順 2 を次に直す。(a) 自分が `didChange` した文書は `version >= min_version` で待つ（basedpyright はバーストを畳んで最後の版だけ、ruff は版ごと。`==` ではなく `>=`）。(b) 依存元の文書は版が旧いまま再送されるので、`didChangeWatchedFiles` 送信後に受信した最初の診断＋ 300 ms の静止で「揃った」とする。(c) 複数文書を `didOpen` した直後の**空の診断は「きれい」と見なさない**（`$/progress end` または最初の受信から 300 ms 静止まで `unknown`）。想定待ち時間: basedpyright は `didChange` から約 0.3 s、ruff は 1 ms 未満。
7. **§7.5.2 `indexing → ready`**: basedpyright は単一文書では `$/progress` を出さない。`ready` は「`initialize` 応答後、最初に開いた文書の実診断を受信」または「`$/progress end`」の早い方。`didOpen` 直後の要求はサーバー内で約 0.6 s 待たされて正しい結果が返る（3 秒の `LSP_TIMEOUT_*` に収まる）ので、`indexing` 中の要求を `None` で返す（ADR-6 (b)）設計は安全側であり変更不要。ruff は起動 12 ms で `ready`。
8. **§7.7 手順 2（再索引）**: 設計どおり **`workspace/didChangeWatchedFiles` が必須**（ディスク書き換えだけでは診断が更新されない）。`references` / `rename` / `callHierarchy` のために参照元を `didOpen` する必要は無い（診断を取りたいときだけ開く）。ruff は動的登録に未対応の旨の警告を stderr に出すが影響なし。
9. **§7.5.2 / §6.5（終了）**: `shutdown` → `exit` で起動口から node までの 4 段が 1 秒以内に全部終わる。`ProcessRegistry` は起動口の PID を持てばよい。起動口の `terminate` が子孫に及ぶことは実測済みだが、固まった子の `kill` は未実測なので、ジョブオブジェクトか `taskkill /T` を保険にする。

## 使うコードの型
```python
import os, shutil, sys, time
from urllib.parse import unquote, urlparse

def find_server(name: str, root: str) -> str | None:        # 探索順: 環境変数 → .venv → PATH
    if v := os.environ.get("LUCIANKE_LSP_PYTHON_CMD"):
        return v
    for sub in ("Scripts", "bin"):
        for ext in (".exe", ""):
            p = os.path.join(root, ".venv", sub, name + ext)
            if os.path.isfile(p):
                return p
    return shutil.which(name)

CMDS = {"basedpyright": [find_server("basedpyright-langserver", root), "--stdio"],
        "ruff": [find_server("ruff", root), "server"]}
# PATH はそのままでよい（Node は .venv の nodejs_wheel が使われる）。シェルは介さない。

# --- initialize（両サーバー共通） ---
params = {
    "processId": os.getpid(), "clientInfo": {"name": "lucianke", "version": "0"},
    "rootUri": root_uri, "workspaceFolders": [{"uri": root_uri, "name": root_name}],
    "locale": "en",                                           # basedpyright の診断を英語に固定
    "capabilities": {
        "general": {"positionEncodings": ["utf-8", "utf-16"]},
        "textDocument": {
            "synchronization": {"dynamicRegistration": False},
            "publishDiagnostics": {"versionSupport": True, "relatedInformation": True, "tagSupport": {"valueSet": [1, 2]}},
            "hover": {"contentFormat": ["markdown", "plaintext"]},
            "rename": {"prepareSupport": True},
            "codeAction": {"dataSupport": True, "isPreferredSupport": True, "resolveSupport": {"properties": ["edit"]},
                           "codeActionLiteralSupport": {"codeActionKind": {"valueSet": ["", "quickfix", "source", "source.organizeImports", "source.fixAll"]}}},
            "callHierarchy": {}},
        "workspace": {"configuration": True, "workspaceFolders": True, "applyEdit": False,
                      "workspaceEdit": {"documentChanges": True, "resourceOperations": []}},
        "window": {"workDoneProgress": True}}}
# 応答: encoding = result["capabilities"].get("positionEncoding", server_def.position_encoding_default)
# そのあと notify("initialized", {})

# --- サーバーからの要求への返答（on_request） ---
def on_server_request(method, p):
    if method == "workspace/configuration":                   # basedpyright だけが尋ねる（section = "python" / "basedpyright"）
        return [{"pythonPath": python_exe, "analysis": {"diagnosticMode": "openFilesOnly"}} if it.get("section") == "python" else {}
                for it in p["items"]]
    if method in ("window/workDoneProgress/create", "client/registerCapability", "client/unregisterCapability"):
        return None
    if method == "workspace/applyEdit":
        return {"applied": False}                              # 適用はしない（書くのは EditTransaction だけ）
    raise LspMethodNotFound(method)                            # error -32601 を返す

# --- URI の正規化（受信） ---
def uri_to_path(uri: str) -> str:
    p = unquote(urlparse(uri).path)
    if sys.platform == "win32" and len(p) > 2 and p[0] == "/" and p[2] == ":":
        p = p[1:]                                              # /s:/work → s:/work（basedpyright は小文字ドライブ）
    return os.path.normcase(os.path.realpath(p))

# --- WorkspaceEdit の取り出し（changes / documentChanges の両形。適用は後ろの編集から） ---
def file_edits(we: dict) -> dict[str, list[dict]]:
    out: dict[str, list[dict]] = {}
    for uri, edits in (we.get("changes") or {}).items():
        out.setdefault(uri_to_path(uri), []).extend(edits)
    for dc in we.get("documentChanges") or []:
        if "kind" in dc:                                       # create / rename / delete
            raise Unsupported("resource operation")
        out.setdefault(uri_to_path(dc["textDocument"]["uri"]), []).extend(dc["edits"])   # version は null
    return out

# --- 診断の版の判別 ---
def on_publish(p):
    v = p.get("version")                                       # didOpen / didChange で送った版。無ければ None
    store.put(uri_to_path(p["uri"]), v, p["diagnostics"], time.monotonic())
# 待つ側: 自分が didChange した文書は version >= min_version（basedpyright は畳み、ruff は版ごと）。
#         依存元は version が旧いままなので、didChangeWatchedFiles 送信後の受信＋300 ms 静止で判断。
#         複数文書の didOpen 直後の n == 0 は未確定として扱う。

# --- 終了 ---
# await request("shutdown", None); notify("exit", None); await proc.wait()   # 1 秒待って残れば terminate → kill
```
