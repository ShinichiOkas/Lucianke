# S-08 dulwich による Git の直読（参照解決・blob・差分・履歴・ignore・status）

実施日 2026-10-29。Windows 11 Home 10.0.26300、CPython 3.12.11、dulwich 1.2.20（C 拡張 `_objects` あり。Apache-2.0 OR GPL-2.0-or-later）。判定: **部分合格**。M1 の範囲（参照解決・blob・STAGED・`.gitignore`・不変性）は合格で 1〜5 ms。**`log --follow` 相当は F-PY 規模で不合格**（dulwich の `Walker` が 13〜16 秒、自前の path 限定 walk でも 1.8 秒。`git log --follow` は 106 ms）。

## 確かめたこと
対象はこのリポジトリ（51 コミット・166 ファイル・ルーズオブジェクトのみ）と、F-PY 規模の代役として pallets/click（3379 コミット・178 ファイル・pack 1 本・タグ 71。`%TEMP%` に clone して終了時に削除）。合否と一致の正解は `git` CLI（`rev-parse`・`diff-tree -M50%`・`log --follow`・`check-ignore`・`status`）。計測は warm（同一 `Repo`）の中央値と、`Repo` を開き直した値。手元の他の役が並行して動いており、数値は ±30% ほど揺れる。再現は `spikes/s08_dulwich/run.py`。

## 設計への反映（推奨）
1. **§7.9.1 `resolve_revision`**: 下の許可リスト版にする（`parse_commit` + `~N`/`^N`）。例外は `KeyError` / `ValueError` / `AmbiguousShortId` の 3 つを `E_REVISION_NOT_FOUND` に束ねる（曖昧は `details.reason: "ambiguous"`）。4 桁以上の短縮 SHA は click 規模で 5 ms なので、`git_commits` を先に引く最適化（§7.9.1 末尾）は M1 では要らない。
2. **§7.9.1 `GitRepo`**: `Repo` を保持しない。要求ごとに `with Repo(...)` で開閉する（開き直しは +1〜3 ms）。Windows で pack を掴んだままだと利用者の `git gc` が `winerror=32` で失敗する。`open()` は `Repo.discover` ではなく `Repo(root)`（`.git` が無ければ `None`、`NotGitRepository`）。モノレポのサブディレクトリを作業ルートにする場合のパス前置は M2 で扱う。
3. **§7.9.1 手順 7（不変性）**: 「`status` は `optional_locks=False` を MUST」を足す。受入の機械検査は `git status` を先に 1 回流してから `index` の sha を測る順にする。
4. **§7.9.1 `read_blob`**: `lookup_path` の `KeyError` / `NotTreeError` / `SubmoduleEncountered` と、`Tree` が返る場合（ディレクトリ）を `None` にする。ツリーのパスは UTF-8 の `bytes`。
5. **§7.9.2 履歴（T-17 / T-18）**: **dulwich の `Walker` は使わない**（F-PY 規模で 13 秒超）。推奨は、履歴専用に **`git` 子プロセス（読み取り専用の `git log --follow` と `git diff-tree -r -M50%`、`core/procs` 経由）を許可**し、§7.9.2 の「シェルの `git` を起動しない（SHOULD NOT）」に例外を書く（実測 106 ms）。`git` が無い環境のフォールバックは自前の path 限定 walk を `max_commits=500` に区切る形（392 ms。git と完全一致はしない）。どちらも `max_commits` を仕様の引数にする。
6. **§7.9.2 差分**: 改名検出は `rename_threshold=50`（git 既定）。大きな差分（100 ファイル超）は 300 ms 級で、改名の判定が git と 1 件ずれ得る。T-18 の `RENAMED` は本体ハッシュ一致が主なので影響は小さい。
7. **§7.3.6 の watcher フィルタ**: `.gitignore` の評価に `IgnoreFilterManager` を使える（1,000 パス 50 ms 以下）。ディレクトリは `dir/` で渡し、`may_prune_directory` で走査を刈る。fnmatch の自前サブセットは不要。
8. **OD-20（仕様書 §17）**: **dulwich を M1 の第一候補として維持**（M1 の用途である 1・2・3・6・8 は合格で、解決・blob・STAGED は 1〜5 ms）。M2 の履歴だけ「(a) dulwich ＋ 履歴専用の `git` 子プロセス」とする案を加える。(b) pygit2 は今回測っておらず、`Walker` 相当が C で速いかは M2 のベンチ（NFR-PERF-2）で L-3 の手続きに従って測る。**R-7（S-8 不合格 → OD-20 の (b) か (c)）は、「M1 は維持・M2 履歴は (c) 部分採用」と読み替える**ことを推奨。

## 使うコードの型
```python
import re
from pathlib import Path
from dulwich.diff_tree import CHANGE_COPY, CHANGE_RENAME, RenameDetector, tree_changes
from dulwich.ignore import IgnoreFilterManager
from dulwich.index import ConflictedIndexEntry
from dulwich.object_store import iter_tree_contents
from dulwich.objects import Blob
from dulwich.objectspec import AmbiguousShortId, parse_commit, parse_object
from dulwich.repo import Repo

class RevisionNotFound(Exception): ...

_BAD = re.compile(r"[\s:?*\[\\]|\.\.|@\{|^$")
_SPLIT = re.compile(r"^(?P<base>.+?)(?P<suffix>(?:[~^]\d*)*)$")

def open_repo(root: Path) -> Repo | None:            # 呼び出し側は with で閉じる（Windows の pack ハンドル）
    try:
        return Repo(str(root))
    except Exception as e:                           # dulwich.errors.NotGitRepository
        if type(e).__name__ == "NotGitRepository":
            return None
        raise

def resolve_revision(repo: Repo, rev: str) -> str:   # WORKING_TREE / STAGED は呼び出し側で先に分岐
    m = _SPLIT.match(rev)
    if not m or _BAD.search(m["base"]) or "^{" in rev:     # @{..} a..b :path ^{} は対応外
        raise RevisionNotFound(rev)
    try:
        commit = parse_commit(repo, m["base"])             # 参照・リモート追跡・短縮 SHA(4桁〜)・注釈付きタグの剥がし
        if m["suffix"]:
            commit = parse_commit(repo, parse_object(repo, commit.id + m["suffix"].encode()))
    except (KeyError, ValueError, AmbiguousShortId) as e:
        raise RevisionNotFound(rev) from e
    return commit.id.decode("ascii")

def read_blob(repo: Repo, commit_sha: str, path: str) -> bytes | None:
    tree = repo[repo[commit_sha.encode("ascii")].tree]
    try:
        _mode, sha = tree.lookup_path(repo.object_store.__getitem__, path.encode("utf-8"))
    except Exception as e:                           # KeyError / NotTreeError / SubmoduleEncountered
        if type(e).__name__ in ("KeyError", "NotTreeError", "SubmoduleEncountered"):
            return None
        raise
    obj = repo[sha]
    return obj.data if isinstance(obj, Blob) else None     # ディレクトリは None

def read_staged_blob(repo: Repo, path: str) -> bytes | None:
    try:
        entry = repo.open_index()[path.encode("utf-8")]    # 読むだけ（ロックも書き込みもしない）
    except KeyError:
        return None
    if isinstance(entry, ConflictedIndexEntry):
        entry = entry.this or entry.ancestor or entry.other
        if entry is None:
            return None
    return repo[entry.sha].data

def list_tree(repo: Repo, commit_sha: str):                # 再帰。(path, mode, sha)
    for e in iter_tree_contents(repo.object_store, repo[commit_sha.encode()].tree):
        yield e.path.decode("utf-8"), e.mode, e.sha

LETTER = {"add": "A", "delete": "D", "modify": "M", "rename": "R", "copy": "C"}

def changed_files(repo: Repo, a_sha: str, b_sha: str, *, threshold: int = 50):   # git 既定の 50%
    store = repo.object_store
    rd = RenameDetector(store, rename_threshold=threshold)
    for c in tree_changes(store, repo[a_sha.encode()].tree, repo[b_sha.encode()].tree, rename_detector=rd):
        yield (LETTER[c.type], c.old.path.decode() if c.old and c.old.path else None,
               c.new.path.decode() if c.new and c.new.path else None)

# 履歴は Walker を使わない。git 子プロセスを履歴専用に許可する（読み取り専用、LC_ALL=C、core/procs 経由）:
#   git -C <root> log --follow --format=%H -n <max_commits> -- <path>        # 106 ms（click の core.py、431 件）
#   git -C <root> diff-tree -r -M50% --name-status <a> <b>
# 自前フォールバック: spikes/s08_dulwich/run.py の file_log_fast（max_commits=500 で 392 ms。git と完全一致はしない）。

def ignore_filter(repo: Repo) -> IgnoreFilterManager:      # 作業ごとに 1 回作る（2〜3 ms）
    return IgnoreFilterManager.from_repo(repo)             # .gitignore と info/exclude とグローバル除外

def is_ignored(mgr: IgnoreFilterManager, rel_posix: str, *, is_dir: bool) -> bool:
    return mgr.is_ignored(rel_posix + "/" if is_dir else rel_posix) is True      # ディレクトリは必ず末尾 /

def worktree_status(repo: Repo):
    from dulwich import porcelain                          # import は遅延（+70 ms）
    # optional_locks=False は MUST: 既定は stat キャッシュ更新で .git/index を書き換える
    return porcelain.status(repo, untracked_files="normal", optional_locks=False)   # .staged / .unstaged / .untracked（bytes）
```
